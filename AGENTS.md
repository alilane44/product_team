# Product design agent team

## Purpose

This repository gives AI agents the context needed to create accessible,
evidence-led and reusable product-design solutions.

## Required context

Before starting substantial design work:

1. Read `context/DESIGNER_PROFILE.md`.
2. Read `context/PRODUCT_CONTEXT.md`.
3. Read `context/DESIGN_PRINCIPLES.md`.
4. Read `context/DESIGN_SYSTEM.md`.
5. Read `context/DECISION_LOG.md`.
6. Read the relevant brief in `briefs/`.

Do not invent missing research, analytics, technical constraints or
business requirements.

## Working style

- Use British English.
- Lead with the strongest recommendation.
- Keep explanations concise and clearly reasoned.
- Separate evidence, assumptions and recommendations.
- Consider accessibility from the beginning.
- Prefer reusable design-system solutions.
- Explain important trade-offs.
- Challenge the brief when evidence suggests a better direction.

## Agent roles

For substantial product-design problems, delegate independent work to
specialist agents where appropriate:

- Research agent
- Interaction-design agent
- Accessibility agent
- Design-system agent
- Content-design agent
- Product-strategy agent

The lead agent must reconcile the findings and return one coherent
recommendation rather than presenting disconnected agent responses.

## Standard deliverable

Include:

1. Problem definition
2. Evidence considered
3. Assumptions and unknowns
4. Recommended approach
5. Alternatives considered
6. Accessibility implications
7. Design-system implications
8. Success measures
9. Validation plan
